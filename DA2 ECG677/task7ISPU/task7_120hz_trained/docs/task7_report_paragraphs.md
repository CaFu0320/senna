# Task 7 — Experimental retraining results (paste-ready technical notes)

The LSM6DSO16IS ISPU was configured with a stable 6-axis Madgwick attitude estimator operating at 208 Hz. The STM32F401RE/AlgoBuilder Sensor Hub was set to a 120 Hz timer-based export rate. The recorded quaternion timestamps confirmed approximately 120.5 samples/s, although the ISPU itself does not use a native 120 Hz processing rate. The quaternion order used for subsequent feature extraction was q0 (scalar w), q1 (x), q2 (y) and q3 (z).

Three approximately 30-second new recordings were collected, one per class (Static, Horizontal and Vertical). The logs contained previously appended 100 Hz sessions; these were excluded, retaining 3,653 Static, 3,655 Horizontal and 3,659 Vertical samples from the latest approximately 120 Hz sessions. The classifier used 42-sample windows with a 21-sample hop, corresponding to approximately 0.35 s windows and a new prediction every 0.175 s. Windows containing a quaternion with norm deviating from unity by more than 0.02 were excluded; this affected two Horizontal windows.

A conventional ANOVA/RFE-style QUAT+FE pipeline was compared with a motion-focused quaternion feature subset. The conventional tree selected eight of 24 engineered features through random-forest RFE and achieved 53/78 (67.95%) on the final chronological test windows. Because the absolute quaternion components drifted with heading or starting orientation, the adapted method retained only the variance and peak-to-peak range of each quaternion component (eight of the original 24 candidate features), reducing reliance on orientation offsets. Its decision tree contained 17 nodes, nine leaves, and a maximum depth of four, and achieved 288/307 (93.81%) training accuracy, 75/78 (96.15%) validation accuracy, and 75/78 (96.15%) on the last chronological test windows. The final test confusion matrix (rows: Horizontal, Static, Vertical; columns in the same order) was [[26,0,0],[0,26,0],[3,0,23]]. These results are exploratory because each class comes from a single physical recording; future independently recorded trials must be used before claiming generalization.

The new tree was exported as JSON and C struct nodes and integrated with the stable Madgwick source in a MEMS Studio ISPU project. Desktop C tests comparing the C feature extraction/tree to the exported reference on 463 windows yielded identical predictions. Hardware deployment, accurate activity labels under new orientations, memory/latency, UART and power benchmarks have not yet been verified for this updated model and must not be marked complete in the report without corresponding evidence.

**Limitations:** A quaternion encodes orientation, not displacement. Keeping the board's orientation fixed during vertical or horizontal translation can yield little change in the inputs, and no quaternion-only model can universally infer translation direction under such conditions. Furthermore, the recording is rounded to 0.001 quaternion units and some thresholds are small; independent hardware tests are especially important.
